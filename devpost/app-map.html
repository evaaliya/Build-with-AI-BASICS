Moo — App Map

A take-home guide to the code, generated after the build. This is a snapshot and can drift.

What it is

Moo is a village livestock-biosecurity PWA. It tracks each animal's Foot-and-Mouth vaccination deadline, lets a farmer book a visit with the village vet and see a queue number, and awards trophies and points only when the vet confirms the vaccination (status = verified). Sign in is email/password for everyone; veterinarians also apply with a license photo and an individual access code issued by the project owner. There is a "Try demo" path without an account. Muzzle recognition remains as a helper to identify an animal.

One action, traced

Core product action: the vet confirms a vaccination → the animal's status becomes green and the farmer gets a trophy.

UI button data-act="vdone" → vDone() in app/app.js → applyVerifiedVaccination() in app/rewards.js (writes status: 'verified') → rewards evaluate verified records only → Home/status chips show protected (green) and the trophy shelf updates.

Code route

Reference route (documented from the finished code; not toured live by the learner in this pass).

1. app/app.js → vDone() (handler data-act="vdone")
Vet Today queue: marks the booking done, calls applyVerifiedVaccination on each animal, updates the booking, toasts success, and notifies the farmer thread.

2. app/rewards.js → applyVerifiedVaccination() / evaluate()
Appends a vaccination with status: 'verified' and validUntil. evaluate() ignores non-verified records when granting trophies; reminders use REMIND_AT = [30, 7, 1].

3. app/logic.js → animalStatus() / pointsForVaccinationRecord()
Status chips (ok / soon / urgent / overdue) come from the latest verified FMD record. claimed awards 0 points; verified awards points.

Related: how the farmer got into the queue

confirmBook() in app/app.js → bookSlot() in app/store.js → SQL RPC book_slot in schema-v2.sql (atomic capacity + queue number).

To change this, start here

  • Reminder thresholds (30 / 7 / 1) — REMIND_AT in app/rewards.js (and matching UI copy in app/i18n.js / Home steps).
  • Recognition constants — MATCH_THRESHOLD, MATCH_MARGIN, FRAMES_TO_CAPTURE in app/recognition.js; re-measure with tools/calibrate.html.
  • Add a language — add a locale object under each key in STRINGS in app/i18n.js and extend LANGS.
  • Vet application review — admin UI in app/app.js (loadAdminApps / doReviewApp); SQL review_vet_application in schema-v3-auth.sql; submissions via Edge Function supabase/functions/submit-vet-application/.

A practice to reuse

The UI never showed that a farmer could self-promote to vet or that neighbours could read another farm's vaccination history. The RLS suite in tests/rls/rls.mjs and the write-up in tests/TEST-REPORT.md found those holes; fixes landed as protect_profile_role and the animals_public view (schema-v4-vet-code.sql). Lesson: test the data rules, not only the screens.
