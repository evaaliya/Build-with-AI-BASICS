Moo — App Map

A take-home guide to the code, generated after the build. This is a snapshot and can drift.

What it is

Moo identifies a stray cow, sheep, or horse by its face and shows its owner. A free in-browser model (MobileNet) turns each animal's face into a 1280-number "fingerprint"; scanning compares fingerprints by similarity. Everything lives in the browser's localStorage for the POC.

One action, traced

Scan an animal → the camera captures a frame → fingerprintOf() turns it into numbers → findMatch() finds the closest registered animal → the name and owner appear.

Code route

1. app/app.js → onScan()
The Scan button's handler. Captures a frame, calls fingerprintOf(), then findMatch(), and renders the result card.

2. app/recognition.js → fingerprintOf() and findMatch()
fingerprintOf() loads MobileNet and returns the 1280-number fingerprint. findMatch() compares it to every stored animal with cosine similarity.

3. app/store.js → addAnimal() / getAnimals()
Where animals (and their fingerprints) are saved to and read from localStorage.

To change this, start here

  • Add a species — edit the <select> options in app/index.html (register form).
  • Tune recognition — the confidence threshold is 0.6 in onScan() in app/app.js.
  • Go multi-user — replace the localStorage calls in app/store.js with Firebase (see README.md).

A practice to reuse

There is no free "animal Face ID" API, so the build used the honest stand-in: an embedding + nearest-neighbor match (recorded in devpost/spec.md > Decisions and Open Issues). When a "magic" API doesn't exist, a small model that turns inputs into numbers and compares them is a reusable pattern.
